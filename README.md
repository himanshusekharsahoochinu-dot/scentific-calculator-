# 🧮 Scientific Calculator

A simple and user-friendly **Scientific Calculator** built using **HTML, CSS, JavaScript, Python, and Flask**.

This project performs basic arithmetic as well as scientific mathematical operations through a clean and interactive interface.

---

## 🚀 Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 📊 Percentage calculation
- √ Square root
- x² Square
- xʸ Power calculation
- sin, cos, tan
- Logarithm
- Natural logarithm
- Factorial
- π (Pi)
- e (Euler's number)
- Brackets and decimal calculations
- Clear and delete functions
- Calculation history
- Backend API using Flask
- CORS support
